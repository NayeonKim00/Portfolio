# Paper Replication

Fama-French 1992 계열의 size-beta empirical test를 복제한 프로젝트입니다.

## Structure

| Folder | Description |
| --- | --- |
| [ff1992-replication](ff1992-replication) | Sequential notebooks, input data, generated output data |

## Notebook Order

1. [0. Market portfolio.ipynb](ff1992-replication/0.%20Market%20portfolio.ipynb)
2. [1. Pre-ranking beta.ipynb](ff1992-replication/1.%20Pre-ranking%20beta.ipynb)
3. [2. Size-beta portfolio.ipynb](ff1992-replication/2.%20Size-beta%20portfolio.ipynb)
4. [3. Fama-Macbeth.ipynb](ff1992-replication/3.%20Fama-Macbeth.ipynb)
5. [4. Table V.ipynb](ff1992-replication/4.%20Table%20V.ipynb)

## Data

- `input/`: raw or prepared input CSV files
- `output/`: intermediate and final CSV outputs generated by the notebooks
- `output/monthly_panel_data.csv` is intentionally excluded from GitHub because it is larger than 100MB. It can be regenerated by running `3. Fama-Macbeth.ipynb`.

## Topics

- Market portfolio construction
- Pre-ranking beta estimation
- Size-beta portfolio sorting
- Fama-MacBeth regression
- Replicated table generation
